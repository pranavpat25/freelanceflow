# FreelanceFlow — Full Stack Freelance Marketplace

## Overview
A full stack marketplace where freelancers post services 
and clients browse, book, and manage orders.

## Tech Stack
- Frontend: React.js
- Backend: Node.js, Express.js
- Database: MongoDB
- Auth: JWT
- Deployment: Vercel + Render

## Features
- Service listing with category filters
- Role-based dashboards (freelancer/client)
- Order management with real time status updates
- Review and rating system
- JWT authentication
